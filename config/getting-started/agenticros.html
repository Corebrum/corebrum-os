AgenticROS

AgenticROS · agenticros.com AgenticROS Skills · skills.agenticros.com AgenticROS Cloud · cloud.agenticros.com

After ROS 2 is installed, Super+Space lists AgenticROS. Choosing it builds the checkout beside this one, or clones it when that directory is missing. It then runs agenticros init --yes. That puts the CLI and every agent’s MCP server on rmw_zenoh_cpp.

AgenticROS Skills lists, searches, installs, or removes a skill through agenticros skills. Refresh does not install a skill. An agent that wants a skill waits until you answer Yes.

AgenticROS Cloud (ARC) opens cloud.agenticros.com in Firefox. The row does not install a browser.

The AgenticROS commands page lists the commands this desktop runs.

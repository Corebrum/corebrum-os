Desktop

Super+Space opens the menu. The Files row opens Thunar. When Ubuntu Desktop also installed Nautilus, the menu hides that second Files entry. After a desktop install, reboot. The login screen is on VT 7. Ctrl+Alt+F1 is a text console. The first login asks to install ROS 2, then RealSense, then AgenticROS, then the AI agents. Each step has Install, Skip, and Exit. Exit remembers that choice, and later logins leave the wizard closed. Super+Space can still install each piece on its own.

Super+Return opens a terminal. Super+Shift+Return opens Firefox, which starts on this welcome set. Super+Space Getting Started shows the Corebrum icon and opens this guide again in Firefox. The Keybindings page lists the rest of the shortcuts. A new window splits the longer side of the focused tile. A wide tile opens the next window beside it, and a tall tile opens the next one below. Super+Arrows move to the tile in that direction on the screen. Super+Shift+Arrows swap with that tile. The top left of the bar shows workspaces 1 through 5. Super+1 through Super+5 switches to that workspace.

The desktop uses the same Corebrum wallpaper as the login screen. Super+Space Wallpaper picks a different image for this account.

Super+Escape locks the screen on the login wallpaper. Login asks for the username and password under the Corebrum logo. The lock screen shows the same logo, a password field in the center, and Unlock. The time and date are in the top right. Type the account password and press Enter, or press Unlock.

Super+Space Autolock sets the idle timer. The rows are Stay awake, 5 minutes, 10 minutes, 30 minutes, and 1 hour. The current row is marked on. Choosing a time saves it, leaves Stay awake on, and shows the list again with that mark. Escape closes the list. Stay awake, or Super+Shift+Escape, pauses the timer until it is turned off or the session ends.

Desktop

Super+Space opens the menu. The first login asks to install ROS 2, then RealSense, then AgenticROS, then the AI agents. Each step has Install, Skip, and Exit. Exit remembers that choice, and later logins leave the wizard closed. Super+Space can still install each piece on its own.

Super+Return opens a terminal. Super+Shift+Return opens Firefox, which starts on this welcome set. Super+Space Getting Started opens this guide again in Firefox. The Keybindings page lists the rest of the shortcuts.

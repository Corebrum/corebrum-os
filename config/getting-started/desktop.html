Desktop

Super+Space opens the menu. The Files row opens Thunar. When Ubuntu Desktop also installed Nautilus, the menu hides that second Files entry. After a desktop install, reboot. The login screen is on VT 7. Ctrl+Alt+F1 is a text console. The first login asks to install ROS 2, then RealSense, then Corebrum Synapse, then the AI agents. Each step has Install, Skip, and Exit. Exit remembers that choice, and later logins leave the wizard closed. Super+Space can still install each piece on its own.

Super+Return opens a terminal. Super+Shift+Return opens Firefox, which starts on this welcome set. Super+Space Getting Started shows the Corebrum icon and opens this guide again in Firefox. The Keybindings page lists the rest of the shortcuts. A new window splits the longer side of the focused tile. A wide tile opens the next window beside it, and a tall tile opens the next one below. Super+Arrows move to the tile in that direction on the screen. Super+Shift+Arrows swap with that tile. The top left of the bar shows workspaces 1 through 5. Super+1 through Super+5 switches to that workspace.

The desktop uses the same Corebrum wallpaper as the login screen. Super+Space Wallpaper picks a different image for this account.

Super+Escape locks the screen on the login wallpaper. Login asks for the username and password under the Corebrum logo. The lock screen shows the same logo, a password field in the center, and Unlock. The time and date are in the top right. The login picture and the lock picture glitch for a moment at each minute of the system clock. The username and password fields stay still. Type the account password and press Enter, or press Unlock.

Super+Space Autolock sets the idle timer. The rows are Stay awake, 5 minutes, 10 minutes, 30 minutes, and 1 hour. The current row is marked on. Choosing a time saves it, leaves Stay awake on, and closes the list. Escape closes the list without a change. Stay awake, or Super+Shift+Escape, pauses the timer until it is turned off or the session ends.

Super+Space Power lists Log out, Reboot, and Power off. Each row asks again. Log out is the same exit as Super+Shift+E and returns to the login screen. Cancel leaves the session running.

Ubuntu Desktop and the NVIDIA desktop

Ubuntu Desktop and the NVIDIA Jetson image start GNOME. Corebrum installs on that same machine. Before the install, boot to a text console:

sudo systemctl set-default multi-user.target
sudo reboot

Log in after the reboot and install the Corebrum desktop. The installer records the previous login program in /etc/corebrum/desktop.state. The next boot opens Corebrum. GNOME stays installed. One desktop runs at a time. Switching takes a reboot.

To open the Ubuntu or NVIDIA desktop on the next boot, leave that state file in place:

previous="$(grep '^previous_display_manager=' /etc/corebrum/desktop.state | tail -n 1 | cut -d= -f2-)"
if [[ -z "$previous" ]]; then
  printf '%s\n' "No previous greeter is recorded in /etc/corebrum/desktop.state"
  exit 1
fi
sudo systemctl disable greetd.service
sudo ln -sfn -- "$previous" /etc/systemd/system/display-manager.service
sudo systemctl set-default graphical.target
sudo reboot

To open Corebrum on the next boot:

sudo rm -f /etc/systemd/system/display-manager.service
sudo systemctl enable greetd.service
sudo systemctl set-default graphical.target
sudo reboot

sudo corebrum install desktop, including Super+Space Updates on the Corebrum row, selects the Corebrum login again. To leave Corebrum and open GNOME, uninstall first. That returns the boot target to the text console, so set the graphical target next:

sudo corebrum uninstall desktop
sudo systemctl set-default graphical.target
sudo reboot

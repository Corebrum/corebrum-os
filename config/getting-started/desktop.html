Desktop

Super+Space opens the menu. The idle list is Apps, Learn, Robot, Appearance, Setup, Updates, and System. Enter or Right opens a group. Backspace or Left goes up one level when the search box is empty. Typing finds nested rows, such as Firefox under Apps or Grok under Robot. The Files row under Apps opens Thunar. When Ubuntu Desktop also installed Nautilus, the menu hides that second Files entry. After a desktop install, reboot. The login screen is on VT 7. Ctrl+Alt+F1 is a text console. The first login asks to install ROS 2, then RealSense, then Corebrum Synapse, then the AI agents. Each step has Install, Skip, and Exit. Exit remembers that choice, and later logins leave the wizard closed. Super+Space can still install each piece on its own.

Super+Return opens a terminal. Super+Shift+Return opens Firefox, which starts on this welcome set. Super+Space Learn then Getting Started shows the Corebrum icon and opens this guide again in Firefox. The Keybindings page lists the rest of the shortcuts. A new window splits the longer side of the focused tile. A wide tile opens the next window beside it, and a tall tile opens the next one below. Super+Arrows move to the tile in that direction on the screen. Super+Shift+Arrows swap with that tile. The top left of the bar shows workspaces 1 through 5. Super+1 through Super+5 switches to that workspace.

The desktop uses the same Corebrum wallpaper as the login screen. Super+Space Appearance then Wallpaper picks a different image for this account.

Super+Escape locks the screen on the login wallpaper. Login asks for the username and password under the Corebrum logo. The lock screen shows the same logo, a password field in the center, and Unlock. The time and date are in the top right. The login picture and the lock picture glitch for a moment at each minute of the system clock. The username and password fields stay still. Type the account password and press Enter, or press Unlock.

Super+Space Setup then Autolock sets the idle timer. The rows are Stay awake, 5 minutes, 10 minutes, 30 minutes, and 1 hour. The current row is marked on. Choosing a time saves it, leaves Stay awake on, and closes the list. Escape closes the list without a change. Stay awake, or Super+Shift+Escape, pauses the timer until it is turned off or the session ends.

Super+Space Setup then Timezone shows the current zone on the row. Choosing it opens a searchable list of time zones. Escape cancels. Choosing a zone asks for permission and runs timedatectl set-timezone. The bar clock and the login and lock clocks follow that zone. There is no separate set-time row; NTP keeps the clock. Typing timezone finds the row.

Super+Space Setup then Password opens a terminal and runs passwd for this account. Enter the current password, then the new one twice. Closing the terminal cancels. That same password unlocks login and the lock screen. Typing password finds the row.

Extra tools

  • Wormhole moves a file or folder to another machine on the network. Super+Space Setup then Wormhole says install until the wormhole command is present. Choosing it installs Ubuntu magic-wormhole. Ubuntu 24.04 publishes 0.12.0-1.1 and Ubuntu 26.04 publishes 0.18.0-1build1. Both packages run on arm64 and on amd64. Send prints a short code. Receive on the other machine types that code. The file lands in ~/Downloads when that directory exists. Wormhole asks before it writes the file. The code can travel through the public mailbox. The file bytes go directly when the machines can see each other.
  • Remote desktop shares this screen over VNC. Super+Space Setup then Remote desktop says install until wayvnc is present. Start listens on port 5900 and shows a password. A Mac uses Finder or Screen Sharing with the vnc:// address. The Mac window title says Corebrum. Windows uses TigerVNC Viewer with the address and ::5900. Linux uses Remmina with the address and :5900. The server does not start at login.
  • Transcription works in any app. Control+Space listens on the default microphone for up to 60 seconds. The next press copies the words. Super+V pastes them into the focused window. If transcription is missing, Control+Space asks before it installs Ubuntu pocketsphinx.

Super+Space System lists About, Log out, Reboot, and Power off. About opens a floating window with processor, graphics, memory, storage, Corebrum and Synapse versions, Ubuntu, uptime, and the last apt upgrade. Log out, Reboot, and Power off each ask again. Log out is the same exit as Super+Shift+E and returns to the login screen. Cancel leaves the session running. Typing about or reboot at the Super+Space prompt finds that row.

Ubuntu Desktop and the NVIDIA desktop

Ubuntu Desktop and the NVIDIA Jetson image start GNOME. Corebrum installs on that same machine. Before the install, boot to a text console:

sudo systemctl set-default multi-user.target
sudo reboot

Log in after the reboot and install the Corebrum desktop. The installer records the previous login program in /etc/corebrum/desktop.state. The next boot opens Corebrum. GNOME stays installed. One desktop runs at a time. Switching takes a reboot.

To open the Ubuntu or NVIDIA desktop on the next boot, leave that state file in place:

previous="$(grep '^previous_display_manager=' /etc/corebrum/desktop.state | tail -n 1 | cut -d= -f2-)"
if [[ -z "$previous" ]]; then
  printf '%s\n' "No previous greeter is recorded in /etc/corebrum/desktop.state"
  exit 1
fi
sudo systemctl disable greetd.service
sudo ln -sfn -- "$previous" /etc/systemd/system/display-manager.service
sudo systemctl set-default graphical.target
sudo reboot

To open Corebrum on the next boot:

sudo rm -f /etc/systemd/system/display-manager.service
sudo systemctl enable greetd.service
sudo systemctl set-default graphical.target
sudo reboot

sudo corebrum install desktop, including Super+Space Updates on the Corebrum row, selects the Corebrum login again. To leave Corebrum and open GNOME, uninstall first. That returns the boot target to the text console, so set the graphical target next:

sudo corebrum uninstall desktop
sudo systemctl set-default graphical.target
sudo reboot

Corebrum Synapse

Corebrum Synapse · corebrum.com/synapse Corebrum Skills · skills.corebrum.com Corebrum Cloud · cloud.corebrum.com

After ROS 2 is installed, Super+Space lists Corebrum Synapse. Choosing it builds the checkout beside this one, or clones it when that directory is missing. It then runs synapse init --yes. That puts the CLI and every agent’s MCP server on rmw_zenoh_cpp.

Corebrum Skills lists, searches, installs, or removes a skill through synapse skills. Refresh does not install a skill. An agent that wants a skill waits until you answer Yes.

Corebrum Cloud opens cloud.corebrum.com in Firefox. The row does not install a browser.

The Corebrum Synapse commands page lists the commands this desktop runs.

Corebrum Synapse

Corebrum Synapse · corebrum.com/synapse Corebrum Skills · skills.corebrum.com Corebrum Cloud · cloud.corebrum.com

After ROS 2 is installed, Super+Space Robot then Corebrum Synapse installs it. Choosing it builds the checkout beside this one, or clones it when that directory is missing. It then runs synapse init --yes. That puts the CLI and every agent’s MCP server on rmw_zenoh_cpp.

Corebrum Skills lists, searches, installs, or removes a skill through synapse skills. Refresh does not install a skill. An agent that wants a skill waits until you answer Yes.

Super+Space Robot then Corebrum Cloud opens with a trailing >. The list has Set up, Sign in, Register this robot, Connect, Disconnect, Account status, and Open website. Set up walks synapse login, then synapse register, then synapse connect in a terminal. Open website still runs Firefox on cloud.corebrum.com. The row does not install a browser. A browser-only sign-in does not put an API token on the robot. The Waybar Cloud chip opens the same choices in Fuzzel, with a local status line.

The Corebrum Synapse commands page lists the commands this desktop runs.

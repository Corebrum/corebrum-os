AI Agents

Super+Space AI Agents lists each CLI (Robot holds ROS, RealSense, Synapse, and related tools). The first rows set the Super+A default or clear it; choosing Super+A default: Set picks a catalog agent by name. Each CLI says install until its command is present. Choosing it installs that CLI, or launches it when it is already installed. Super+A opens the default in a floating terminal when that CLI is installed and a default is set. Typing a CLI name, such as grok, at the Super+Space prompt finds that row. The idle menu shows groups, not every CLI.

The desktop profile does not install them. The first launch asks that publisher to sign in. Grok's installer runs as root, then gives ~/.grok back to this account so the CLI can save that sign-in.

Installing an agent before or after Corebrum Synapse writes that agent’s config so the agent uses Corebrum Synapse for ROS on this machine. corebrum agents list shows which CLIs are on PATH. corebrum agents default get, default set <id>, and default clear manage the Super+A choice without installing. corebrum agents update points at Super+Space Updates and does not run a publisher installer.

A skill installed while an agent is already open is visible only after that agent is started again. Super+Space Corebrum Skills reminds you after install. Open the CLI from Super+Space AI Agents.

Ollama

Ollama · ollama.com

Ollama is under Super+Space Robot. It says install until the ollama command is present. After that, the row lists local models and runs one with ollama run. The desktop profile does not install Ollama.

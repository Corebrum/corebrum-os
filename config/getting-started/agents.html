AI Agents

Super+Space lists AI Agents. Each CLI says install until its command is present. Choosing it installs that CLI, or launches it when it is already installed. Typing a CLI name, such as grok, at the Super+Space prompt finds that row. The idle menu still shows AI Agents.

The desktop profile does not install them. The first launch asks that publisher to sign in. Grok's installer runs as root, then gives ~/.grok back to this account so the CLI can save that sign-in.

Antigravity CLI · antigravity.google Claude Code CLI · claude.ai Codex CLI · chatgpt.com/codex Cursor CLI · cursor.com Grok CLI · x.ai/build Hermes CLI · hermes-agent.nousresearch.com OpenClaw · openclaw.ai

Installing an agent before or after Corebrum Synapse writes that agent’s config so the agent uses Corebrum Synapse for ROS on this machine. corebrum agents list shows which CLIs are on PATH. corebrum agents update points at Super+Space Updates and does not run a publisher installer.

Ollama

Ollama · ollama.com

Ollama is its own Super+Space row. It says install until the ollama command is present. After that, the row lists local models and runs one with ollama run. The desktop profile does not install Ollama.

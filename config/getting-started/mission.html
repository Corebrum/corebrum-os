A mission

Install ROS 2, then RealSense, then Corebrum Synapse, then an agent. The camera sees. The agent decides. Corebrum Synapse reaches ROS. ROS moves or speaks.

Reference path (Jetson + drive)

  1. Install JETGPIO and run synapse doctor on the Orin.
  2. sudo corebrum install ros, then RealSense and Synapse from Super+Space.
  3. synapse up real — RealSense and motors (Jetson GPIO on Tegra).
  4. Optional: sudo corebrum install ros --mapping, then Super+Space Synapse → Stack: Real robot (with mapping) or synapse up real --map.
  5. synapse login, synapse register, synapse connect for Cloud teleop and maps.
  6. Install a skill with Super+Space Corebrum Skills; restart the agent so MCP tools reload.

Creep or Treat greets a visitor from depth and does not drive. Skills that need Nav2 or RTAB-Map point you at the mapping stack above; they do not start those services for you.

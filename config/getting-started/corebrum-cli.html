Corebrum commands

corebrum help prints this list. A real install needs root. --dry-run prints the plan and does not change the system.

CommandEffect
corebrum versionPrint the version from VERSION
corebrum statusSay whether base, desktop, services, and ROS are installed, plus RealSense, AgenticROS, and the Skills helper
corebrum doctorRun the validators and print the next command if one fails
corebrum configList /etc/corebrum, logs, and backups
corebrum install baseHeadless Ubuntu foundation. corebrum install headless is the same profile
corebrum install desktopBase, Sway, workstation services, and Node.js 26.x. Add --enable-ssh to also install OpenSSH
corebrum install rosBase profile, ROS 2, and the Zenoh router
corebrum uninstall desktopRemove Corebrum desktop files and restore the previous login program when one was recorded. Ubuntu packages stay installed. The Desktop page explains how to open Ubuntu Desktop or the NVIDIA desktop again
corebrum uninstall rosRemove Corebrum ROS files. The ROS apt packages stay installed
corebrum ros statusDistro, selected RMW, and router state
corebrum ros topicsros2 topic list with the selected RMW
corebrum ros rmw zenohNew shells use Zenoh
corebrum ros rmw fastrtpsNew shells use Fast DDS
corebrum zenoh statusRouter unit and listen address
corebrum zenoh peersRouter address and this machine’s IPv4 addresses
corebrum camera listList RealSense devices, or point at Super+Space
corebrum agents listShow which catalog CLIs are on PATH, with a version when the CLI prints one
corebrum agents updatePoint at Super+Space Updates. It does not run a publisher installer
corebrum update statusList the Updates rows. It does not run apt or git
corebrum speak "text"Say the text with espeak-ng
corebrum speak listenSay each std_msgs/String published on /corebrum/say
corebrum voice listList espeak-ng voices
corebrum voice testSay “Hello from Corebrum.”
corebrum voice set espeakKeep local speech on espeak-ng
corebrum voice enableTurn speech on
corebrum voice disableStop speech until corebrum voice enable
corebrum voice hearTranscribe the default microphone. corebrum voice hear --install installs the recognizer first

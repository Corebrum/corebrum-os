AgenticROS commands

These are the agenticros commands this desktop runs. Super+Space AgenticROS installs the CLI and runs agenticros init --yes. The same menu can run the rows below.

CommandEffect
agenticros init --yesWrite the local ROS config and register agents already on PATH
agenticros statusShow AgenticROS status
agenticros doctorCheck the install. It warns when the RMW file is not rmw_zenoh_cpp
agenticros connectConnect to AgenticROS Cloud
agenticros disconnectDisconnect from AgenticROS Cloud
agenticros loginSign in to AgenticROS Cloud
agenticros start realsenseStart the RealSense camera
agenticros stop realsenseStop the RealSense camera
agenticros start cameraStart the 2D camera
agenticros stop cameraStop the 2D camera
agenticros start motorsStart the motors
agenticros stop motorsStop the motors
agenticros eyesStart the eyes
agenticros stop eyesStop the eyes
agenticros up realBring up the real robot stack
agenticros up sim-amrBring up the simulated AMR stack
agenticros up sim-armBring up the simulated arm stack
agenticros downStop the stack
agenticros mode realSwitch to the real robot
agenticros mode simSwitch to simulation
agenticros mcp setupRegister installed agent CLIs. The menu runs agenticros mcp setup --installed
agenticros skills listList installed skills
agenticros skills searchSearch the skill catalog
agenticros skills installInstall a skill after you answer Yes
agenticros skills removeRemove a skill
agenticros desktopSend the screen to AgenticROS Cloud

Welcome

Corebrum OS is the Physical AI operating system on Ubuntu Server 24.04 and 26.04. The install and the desktop run on both. It is a desktop, ROS 2, a camera, and AI agents that can act through a robot’s body. Ubuntu 24.04 installs ROS 2 Jazzy. Ubuntu 26.04 installs ROS 2 Lyrical. Both lock the screen with the Corebrum logo and a password field.

Super+Space installs and launches each piece. These pages are the Firefox start page. Change that in Firefox settings when you want a different page. Super+Space Getting Started opens this guide again.

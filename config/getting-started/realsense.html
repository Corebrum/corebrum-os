RealSense · realsenseai.com

Super+Space Robot then RealSense installs librealsense, realsense-ros, and pyrealsense2. The first-login wizard keeps this step closed until ROS 2 is installed. Jetson and Raspberry Pi use the same arm64 packages. Corebrum does not rebuild librealsense with CUDA.

After the install, the same menu has two rows. RealSense Viewer launches realsense-viewer. RealSense ROS opens a terminal running ros2 launch realsense2_camera rs_launch.py.

You may rebuild or replace those tools yourself, for example a CUDA librealsense on Jetson. That copy is yours to update and remove. Super+Space Updates → RealSense reruns /usr/local/lib/corebrum/realsense-install.sh at the Corebrum pins when librealsense is already installed. Updates → Ubuntu leaves the RealSense SDK at that pin, so a new RealSense release arrives through a Corebrum update and then Updates → RealSense, or Updates → All. It does not manage operator-owned builds. When one in /usr/local is still what realsense-viewer and the ROS camera node load, the update ends with a warning naming that build and its version.

corebrum camera list lists connected RealSense devices, or points at Super+Space when the camera stack is not installed.

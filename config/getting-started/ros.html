ROS 2

ROS 2 Jazzy · docs.ros.org/en/jazzy ROS 2 Lyrical · docs.ros.org/en/lyrical

Super+Space lists ROS 2 with an install mark until sudo corebrum install ros has been run. Ubuntu 24.04 installs Jazzy. Ubuntu 26.04 installs Lyrical. After that, the ROS menu launches RViz, Gazebo, Nav2, and MoveIt. Typing gazebo, rviz, nav2, or moveit at the Super+Space prompt finds that tool.

A Corebrum terminal already uses Zenoh (rmw_zenoh_cpp). Close a terminal that was open before the install and open another with Super+Return. Topics travel through the Zenoh router. See Zenoh.

Everyday commands

ros2 topic echo subscribes and prints each message. ros2 topic pub publishes. Add --once to read or send a single message. corebrum ros topics is ros2 topic list through the selected RMW.

ros2 topic list
ros2 node list
ros2 topic echo /topic_name
ros2 topic pub /topic_name std_msgs/msg/String "{data: hello}"
corebrum ros topics

Corebrum Synapse commands

These are the synapse commands this desktop runs. Super+Space Corebrum Synapse installs the CLI and runs synapse init --yes. The same menu can run the rows below.

CommandEffect
synapse init --yesWrite the local ROS config and register agents already on PATH
synapse statusShow Corebrum Synapse status
synapse doctorCheck the install. It warns when the RMW file is not rmw_zenoh_cpp
synapse connectConnect to Corebrum Cloud after login and register; fails if signaling does not stay up
synapse disconnectDisconnect from Corebrum Cloud
synapse loginSign in to Corebrum Cloud
synapse registerRegister this robot on Corebrum Cloud after sign-in
synapse whoamiShow Cloud login and whether this robot is registered
synapse start realsenseStart the RealSense camera
synapse stop realsenseStop the RealSense camera
synapse start cameraStart the 2D camera
synapse stop cameraStop the 2D camera
synapse start batteryPublish sensor_msgs/BatteryState from Linux /sys/class/power_supply when a Battery supply exists (see synapse logs battery)
synapse stop batteryStop the battery publisher
synapse start motorsStart the motors
synapse stop motorsStop the motors
synapse eyesStart the eyes
synapse stop eyesStop the eyes
synapse up realBring up the real robot stack
synapse up sim-amrBring up the simulated AMR stack
synapse up sim-armBring up the simulated arm stack
synapse downStop the stack (including the battery publisher when running)
synapse mode realSwitch to the real robot
synapse mode simSwitch to simulation
synapse mcp setupRegister installed agent CLIs. The menu runs synapse mcp setup --installed
synapse skills listList installed skills. Super+Space List also lets you pick a number to remove one
synapse skills searchSearch the skill catalog. Super+Space Search lists matches and installs the owner/skill you pick
synapse skills installInstall owner/skill or @scope/name after you answer Yes. A display name alone 404s
synapse skills removeRemove a registered skill id. Super+Space Remove picks from the same list as List
synapse desktopSend the screen to Corebrum Cloud

Physical AI

Physical AI is an AI that can use a body. The body is the robot. RealSense is how it sees. ROS 2 is how motors, sensors, and tools talk. Corebrum Synapse connects an AI agent to that ROS graph so the agent can take a mission: look, decide, and act.

The reference kit is a Jetson Orin with native GPIO to an L298N motor driver (no Arduino), a RealSense camera, and Corebrum Synapse on rmw_zenoh_cpp. On Tegra, synapse start motors uses JETGPIO when it is installed. Alternates: Raspberry Pi (-b rpi) or x86/ARM with Arduino Firmata (-b firmata).

Install ROS 2 first, then RealSense and Corebrum Synapse. For room mapping and Nav2, install the optional mapping stack with sudo corebrum install ros --mapping or Super+Space ROS → Mapping stack install. Remote drive and live maps use synapse connect and Corebrum Cloud.

Jetson wiring and JETGPIO: see docs/installation/jetson-robot.md on this machine and Synapse hardware.md.

Physical AI

Physical AI is an AI that can use a body. The body is the robot. RealSense is how it sees. ROS 2 is how motors, sensors, and tools talk. AgenticROS connects an AI agent to that ROS graph so the agent can take a mission: look, decide, and act.

The pieces stay separate until you install them. ROS 2 comes first. RealSense and AgenticROS need that install. An AI agent can be installed before or after AgenticROS. Once AgenticROS is installed, that agent uses it for ROS on this machine.

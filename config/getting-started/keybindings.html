Keybindings

Super+Space Keybindings lists these shortcuts. Choosing a row there closes the list. Volume, brightness, Print without Super, and the text console stay off this list.

PressAction
Super+ReturnOpen a terminal
Super+KClear the terminal screen
Control+SpaceTranscribe the microphone
Super+Shift+ReturnOpen Firefox
Super+Shift+FOpen Files
Super+Shift+NOpen Text Editor
Super+WClose the focused window
Super+QClose the focused window
Super+FFullscreen
Super+TFloat or tile the focused window
Super+CCopy
Super+XCut
Super+VPaste
Super+SpaceOpen the application menu
Super+Alt+SpaceOpen the app grid
Super+SToggle the agent scratchpad terminal
Super+EscapeLock the screen. Type the account password and press Enter, or press Unlock
Super+Shift+EscapePause autolock, or resume it
Super+Shift+ELog out and return to the login screen
Super+Shift+CClipboard history
Super+PrintRecord the area, camera, or audio
Super+Shift+PrintStop recording
Super+PCopy a selected area
Super+Shift+PCopy the whole screen
Super+Alt+PRecord the area, camera, or audio
Super+Alt+Shift+PStop recording
Super+ArrowsMove focus to the tile in that direction
Super+Shift+ArrowsSwap with the tile in that direction
Super+1 … Super+5Switch to that workspace
Super+Shift+1 … 5Move the focused window to that workspace

# 0088. Ubuntu Server 24.04 and 26.04

Date: 2026-10-28
Status: Accepted

## Context

Decision 0063 accepted Ubuntu Server 26.04 only. Preflight rejected `noble`. The ROS installer already selected Jazzy for noble and Lyrical for resolute, and RealSense already pinned packages for both codenames. A 24.04 machine never reached those paths.

Ubuntu 24.04 publishes Sway 1.9, swaybg, swayidle, wlgreet, and swaylock for amd64 and arm64. It publishes gtklock 2.1.0. Sway 1.9 locks through `ext-session-lock`, which gtklock gained in 3.0.0. The resolute lock screen is gtklock 4.0.0 and uses `layout` and `style`. That config cannot lock a 24.04 session.

## Decision

- Preflight accepts `ID=ubuntu` with `VERSION_CODENAME=noble` and `VERSION_ID=24.04`, or `VERSION_CODENAME=resolute` and `VERSION_ID=26.04`, on `x86_64` and `aarch64`. Every other release stops before any package is installed. The `ubuntu-server` metapackage is not required.
- `corebrum install ros` installs ROS 2 Jazzy on Ubuntu 24.04 and ROS 2 Lyrical Luth on Ubuntu 26.04. The apt source package and the package manifest were already selected that way.
- The desktop stays on Sway from the Ubuntu archive. The installer does not add a Hyprland PPA.
- Ubuntu 24.04 installs `swaylock` and locks with `/etc/corebrum/sway/swaylock.conf`. The image is `/usr/share/hypr/wall2.png` and the ring is `#3d9a8b`. Ubuntu 26.04 keeps gtklock 4, the centered password field, and the logo.
- Login stays `corebrum-login`. `wlgreet` stays the fallback.
- GitHub Actions runs `make check` on `ubuntu-24.04` and `ubuntu-26.04`.

## Consequences

This decision is the current host target. Decision 0063 remains the record of the 26.04-only period. A 24.04 desktop locks with a ring. A 26.04 desktop locks with the password field. Jetson is still not part of this decision.
